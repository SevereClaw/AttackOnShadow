### Исправление: ошибка USB 31 при подключении

Клавиатура отклоняла пакеты (`A device attached to the system is not functioning [31]`). Скорее всего, программа отправляла их без нужного Report ID. Теперь она читает из описания HID-интерфейса K85, какие Report ID объявлены для служебных отчётов, и пробует их по очереди, как это делает служба официального драйвера (hidapi).

Если не заработает — пришли `usb.txt` из «Настройки → Папка с журналами»: там список интерфейсов клавиатуры с их Report ID и ответ на каждую попытку.
