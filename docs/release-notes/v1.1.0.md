Первый релиз AttackOnShadow — мода для Attack Shark Driver (проверен на драйвере 2.1.79).

### Что внутри
- Тема в стиле Persona 3 Reload, бабочка вместо акулы (логотип, трей, окно)
- Без облака и аналитики: вкладки аккаунта и шаринга убраны, сеть кроме localhost и GitHub заблокирована
- Русские подписи починены и доперёведены, меню трея на русском
- Свой фон из «Внешнего вида» применяется как выбран
- Панель «МОД»: автопрофили по запущенной игре, свои звуки меню, размер окна (Ctrl + колесо)
- Обновление мода прямо из панели
- `uninstall.bat` возвращает оригинал байт в байт
