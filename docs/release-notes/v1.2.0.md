### Установщик и автообновление

- **AttackOnShadow.exe** — установщик в стиле P3R. Сам находит драйвер (даже если он сейчас запущен), ставит, обновляет и удаляет мод. Права администратора спрашивает, только если драйвер лежит в Program Files. Ничего доустанавливать не нужно: работает на встроенном в Windows .NET Framework.
- **Автообновление.** Мод раз в день проверяет релизы на GitHub и сам ставит новую версию, когда драйвер свёрнут в трей и игра из автопрофилей не запущена. Выключается в МОД → Обновления мода.
- **Запуск в трей.** Автозапуск драйвера и перезапуск после обновления теперь стартуют свёрнутыми, без окна.

`install.bat` / `uninstall.bat` по-прежнему работают, если EXE не нравится.

Windows SmartScreen может предупредить о «неизвестном издателе»: файл не подписан. «Подробнее → Выполнить в любом случае».
