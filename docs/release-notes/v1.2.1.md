### Исправление

- Автообновление: разрешён новый адрес GitHub для скачивания файлов релизов (`release-assets.githubusercontent.com`). GitHub постепенно переводит загрузки на него. Без этой правки офлайн-фильтр мода мог бы заблокировать скачивание следующих обновлений.

Если стоит v1.2.0, эта версия встанет сама, когда драйвер будет свёрнут в трей.
