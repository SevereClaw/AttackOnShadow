## AttackOnShadow 2.0 — своё приложение

Больше не мод для Attack Shark Driver, а отдельная программа (~250 КБ), которая говорит с **Attack Shark K85** напрямую по USB. Официальный драйвер не нужен.

### Что есть
- **Слои**: переключение двух слоёв клавиатуры; видит и смену слоя через Fn на клавиатуре
- **Автопрофили**: слой по запущенной игре и возврат на обычный после неё; правила из мода переносятся сами
- **Подсветка**: 19 эффектов, яркость, скорость, направление, свой цвет или радужный
- **Трей**: быстрый выбор слоя, автозапуск сразу в трей
- **Автообновление** из релизов GitHub

### Важно
- Это первая версия, которая общается с клавиатурой сама. Протокол восстановлен по коду официального драйвера, но на живой K85 ещё не проверялся. Если что-то не так — пришли `usb.txt` и `log.txt` из «Настройки → Папка с журналами».
- Attack Shark Driver лучше закрыть, пока работает AttackOnShadow.
- Старый мод из драйвера можно удалить кнопкой в «Настройках».
